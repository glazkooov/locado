# Фото мест

## Как добавить фото

1. Загрузи фото в `assets/images/places/` с именем места: `serebryany-bor.jpg`.
   Размер любой — сайт сам подготовит версии (см. ниже).
2. В `data/places.json` у места: `"photo": "assets/images/places/serebryany-bor.jpg"`.
3. Там же — подпись. Для фото с foto.mos.ru:
   ```json
   "photoCredit": { "author": "mos.ru", "source": "https://www.mos.ru/" }
   ```
   На сайте это строка «Фото: mos.ru» со ссылкой на mos.ru — так требует
   соглашение фотобанка (п. 4.5.2). Если есть ссылка на страницу самого
   снимка на foto.mos.ru — поставь её в `source` вместо главной mos.ru.
   - Другие источники (Wikimedia Commons): `author` — как подписан снимок,
     `source` — страница файла, `license` — `CC BY 4.0`, `CC BY-SA 4.0`,
     `CC BY 3.0`, `CC BY-SA 3.0`, `CC BY 2.0`, `CC BY-SA 2.0` или `CC0`; `"modified": true` — если фото
     кадрировали или меняли цвет;
   - своё фото: `"photoCredit": { "author": "Локадо" }`.

   Без `photoCredit` фото не публикуем: `check-photos.mjs` это покажет.

Вертикальное фото на компьютере обрезается до широкой полосы по центру.
Если главное в кадре ниже или выше центра, сдвинь полосу полем
`"photoFocus": "50% 70%"` (второе число — 0% верх, 100% низ).

У обложки подборки — то же поле `photoCredit` в `data/collections.json`.

## Что делает сайт с фото

GitHub Actions (`.github/workflows/photos.yml`) при загрузке фото в `main`
запускает `tools/photos.py` и через минуту-две коммитит результат:

- само фото — до 2000 px по ширине, обычно 300–500 КБ, без служебных
  данных снимка (модель камеры, координаты);
- копию для карточек — `assets/images/places/sm/<имя>`, 640 px.

Вручную для всех фото: вкладка **Actions → «Фото мест» → Run workflow**.
Локально (из любой папки проекта):

- Mac/Linux: `pip3 install pillow`, затем `python3 tools/photos.py`;
- Windows: `py -m pip install pillow`, затем `py tools\photos.py`.
  Если в ответ на команду просто пишется «Python» или открывается
  Microsoft Store — Python не установлен: поставить с python.org
  (галочка «Add python.exe to PATH») и открыть PowerShell заново.

## Где видна подпись

- Страница места — мелкая строка под первым экраном; подборка — под
  обложкой и под фото каждого места: «Фото: mos.ru» со ссылкой.
- Страница «Фото на сайте» (`photos/`, ссылка в подвале) — все подписанные
  фото списком.

## Проверка

`node tools/check-photos.mjs` — фото без файла, без копии для карточек,
тяжелее 600 КБ, без подписи или без ссылки на источник.

## Откуда можно брать фото

- **foto.mos.ru** — по пользовательскому соглашению фотобанка
  (foto.mos.ru/polzovatelskoe-soglashenie), не по Creative Commons:
  - только некоммерческое использование (п. 4.1). Когда на сайте появятся
    бронирования, платные карточки или реклама — фото заменить или получить
    письменное разрешение, где прямо названы foto.mos.ru и коммерческое
    использование;
  - подпись «mos.ru» с активной ссылкой на mos.ru (п. 4.5.2);
  - нельзя: раздел «Культурное наследие» и закрытые альбомы (п. 4.6);
  - только снимки, подписанные mos.ru или фотографом mos.ru; с подписью
    агентства (ТАСС, РИА, «Москва») — нельзя.
- **Произведения искусства в кадре** (картины в залах, муралы) — у них свои
  авторы, фотобанк прав на них не даёт. Для музеев и галерей надёжнее фото
  фасада или общего вида.
- **Wikimedia Commons** — автор и лицензия указаны на странице файла.
- **Свои фото** — можно всегда.
- **Сайт самого места** — только с разрешения.
- **Яндекс/Google Карты, соцсети, фотостоки** — нельзя.
