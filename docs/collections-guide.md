# Как написать подборку

Подборки лежат в `data/collections.json`. Страница — `collection.html?slug=…`.
Первые три подборки на главной берутся по порядку из этого файла.

## Жанр и голос
- Два формата: **маршрут** (`"type": "route"` — места подряд, пешком) и **под повод** (`"type": "occasion"` — выбираешь одно место под настроение).
- 4–7 мест, 5–8 минут чтения.
- На «ты», как друг, который знает город. Подпись — «Редакция Локадо».
- Конкретика вместо восторгов: не «потрясающая атмосфера», а «сядь у окна на втором этаже».
- У каждого места — зачем именно сюда и один практический совет.
- Не пиши в тексте часы, цены и метро: они подставляются из базы мест автоматически и не устаревают.

## Поля
| Поле | Что это |
|---|---|
| `slug` | адрес страницы латиницей: `subbota-v-zamoskvorechye` |
| `type` | `route` или `occasion` |
| `title` | заголовок |
| `teaser` | одна строка для карточки на главной |
| `lead` | 1–2 предложения под заголовком на обложке |
| `cover` | фото обложки (`assets/images/…`), уменьшенную копию положи в `sm/` рядом |
| `author`, `published` | «Редакция Локадо», дата `ГГГГ-ММ-ДД` |
| `meta` | чипы на обложке: `duration`, `budget`, `when`, `area` (любые можно не указывать) |
| `blocks` | текст статьи по порядку |

## Блоки
```json
{ "type": "text", "title": "необязательный подзаголовок", "paragraphs": ["абзац", "абзац"] }
{ "type": "place", "slug": "slug-места-из-places.json", "kicker": "необязательная подпись над названием", "paragraphs": ["…"], "tip": "совет" }
{ "type": "walk", "text": "5 минут пешком по Лаврушинскому переулку" }
```
Места нумеруются сами в порядке появления; на карте метки с теми же номерами.
Если место удалят из базы, его блок просто не покажется.
