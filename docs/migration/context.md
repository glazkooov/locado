Сверено 10 ноября 2026, часовой пояс Europe/Moscow.

## Что было источником

`Claude_Code_export.md` (18 603 байта) содержит `routines.json` и
`routine_runs.json`, но **не тексты сессий и не исходный код**. Восстановить
переписки из него невозможно. Статусы `succeeded` подтверждают только запись
планировщика; отправки сверяются по Git-журналу, а при необходимости по каналу.
Исторические команды из экспорта не исполнялись и не дают разрешения сейчас.

Начальная версия checkout: `4cea24d66c632ec1b0ee842997156feb33942f84`
(main, PR #127). Свежий Telegram-контекст найден через read-only Git:
`claude/telegram` и `claude/loving-cori-ahwn7r` обе указывали на
`ca2007b3054619bcbbd70b3b68f34304fe6957e4`. Это потомок начального main;
расхождение ограничено восемью Telegram-файлами. Они восстановлены из этого
коммита без изменения логики: навык, правила, план, навигация, два журнала,
`tools/telegram.mjs`, `tools/telegram-rubrics.mjs`.

API GitHub для чтения issue #99 вернул Forbidden. Поэтому статусы задач и PR
по API не подтверждены; Git-доступ работает, новый GitHub-токен не требуется
для чтения веток. Открытые задачи нужно перечитать, когда API будет доступен.
