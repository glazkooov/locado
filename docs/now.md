# Блок «Сейчас» на главной

Сразу под первым экраном — что смотреть в это время года: заголовок,
одна-две фразы и четыре места. Под фото каждого места — «Когда лучше»
из его `story` (а если `story` ещё нет — короткое описание).

## Как поменять

Файл `data/now.json` — список сезонов:

```json
[
  {
    "from": "09-15",
    "to": "10-31",
    "eyebrow": "Сейчас, осенью",
    "title": "Золотая осень — время усадеб",
    "lead": "Пара недель, когда старые парки красивее всего в году.",
    "places": ["kolomenskoe", "tsaritsyno", "kuskovo", "novodevichy-prud"]
  }
]
```

- `from`, `to` — месяц и день, включительно. Период может переходить
  через Новый год: `"from": "12-01", "to": "02-28"`.
- `places` — слаги мест (как в адресе страницы места). Лучше четыре:
  на компьютере они встают в один ряд.
- Подходит первая запись, в которую попадает сегодняшний день. Если ни
  одна не подходит — блока на главной просто нет, ничего не ломается.

Удобно заполнить год вперёд: осень, первый снег, новогодние недели,
зима, весна, лето — и дальше только обновлять места.

Места из блока «Сейчас» в ленте ниже ставятся в конец, чтобы не
повторять то, что человек только что видел. Поле `"featured": true`
у мест больше не используется: раньше по нему собирался блок
«Сейчас в центре внимания».
