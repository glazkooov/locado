# Яндекс Метрика

Счётчик **113990190**. Код — `scripts/core/analytics.js`.

## Как это устроено

1. Посетитель открывает сайт — `analytics.js` сразу подключает `tag.js`
   Яндекса и инициализирует счётчик. Метрика сама считает просмотры
   страниц, источники, устройства, время на сайте, клики по карте.
2. Плашка cookie уведомляет: оставаясь на сайте, человек соглашается.
   Кнопка «Хорошо» только закрывает плашку (`consent.js` запоминает).
3. «Отключить статистику» в политике (или «Не надо» в старой версии
   плашки) — `tag.js` больше не загружается, цели не отправляются.
4. В важных местах сайт вызывает `goal('имя')` — это событие. В кабинете
   Метрики оно становится целью, только если там заведена цель с таким
   же идентификатором (см. ниже).

Вебвизор включён (`webvisor: true`): он записывает действия посетителя,
это описано в политике и согласии. Формы Яндекса открываются в окне
(iframe) и в запись не попадают. Выключать — вместе с правкой политики.

## Цели — завести в кабинете

Метрика → счётчик → **Настройки → Цели → Добавить цель** →
тип **«JavaScript-событие»** → идентификатор из таблицы.

| Название цели | Идентификатор | Когда срабатывает |
|---|---|---|
| Построить маршрут | `route_click` | кнопка маршрута на странице места или подборки |
| Открыл подборку | `collection_open` | открыта страница подборки |
| Удиви меня | `random_open` | открыто «Случайное место» |
| Поиск | `search` | человек что-то искал в ленте |
| Поиск без результата | `search_empty` | по запросу ничего не нашлось |
| Предложить место | `suggest_open` | открыта форма «Предложить место» |
| Сообщить о неточности | `report_open` | открыта форма на странице места: «Что-то не так?» в справке под фото |
| Установка: открыл | `install_open` | нажал «Добавить на экран телефона» |
| Выбрал раздел | `category_select` | вкладка ленты, карта, «Случайное место», ссылка из меню |
| Выбрал настроение | `mood_select` | карточка настроения на первом экране |
| Выбрал тег | `tag_select` | открыта лента по ссылке с тегом (`?tag=`); на странице места тегов больше нет |
| Нажал «Поделиться» | `share_open` | кнопка на странице подборки; на странице места — «Просто отправить ссылку» в окне «Позвать друга» |
| Позвать друга | `invite_open` | открыто окно «Позвать друга» на странице места (карточка «Идёшь не один?» или кнопка в нижней панели) |
| Открыл карту | `map_open` | «Показать на карте» на странице места (карта грузится только по этой кнопке) |
| Готовый план | `nearby_plan` | открыто окно «Маршрут отсюда» в «Куда пойдём дальше?» |
| Поделился | `share` | выбрал, куда отправить: Telegram, ВК, копирование, меню телефона |
| Установка: установил | `app_install` | сайт установлен (только Android/Chrome) |
| Выбрал подборку | `plan_select` | карточка подборки: главная, «Все подборки», страница места |
| Случайное: открыл место | `random_go` | «Открыть место» в «Удиви меня» |
| Случайное: ещё вариант | `random_reroll` | «Ещё вариант» в «Удиви меня» |
| Случайное: сменил режим | `random_mode` | «Открыто сейчас» ↔ «Любое место» |
| Связаться с местом | `contact_click` | телефон, сайт или соцсеть на странице места |
| Вместе: начал | `together_start` | «Начать листать» в «Выбрать вместе» (параметр — из чего: всё или настроение) |
| Вместе: отправил | `together_send` | отправил ссылку другу: свой выбор или ответ с совпадениями |
| Вместе: открыл ссылку | `together_open` | друг открыл ссылку «Выбрать вместе» |
| Вместе: совпадения | `together_result` | показан экран совпадений (параметр — сколько совпало) |
| Перешёл в канал | `channel_click` | ссылка на Telegram-канал в подвале или в конце подборки (параметр — откуда: `footer`, `collection`) |
| Пришёл из Telegram | `telegram_visit` | открыл сайт по ссылке из канала (`utm_source=telegram`, параметр — рубрика) |

Цели считаются с момента, как их завели: задним числом события
в отчёт по целям не попадают.

## Где смотреть подробности

К целям прикреплены параметры. Отчёт: **Отчёты → Содержание →
Параметры визитов** (или в списке отчётов найти «Параметры визитов»).
Там дерево, которое раскрывается по клику:

- **Поиск → запрос → нашлось / ничего** — что ищут и находят ли;
- **Поиск без результата → запрос** — чего на сайте не хватает;
- **Раздел → Еда → Вкладки ленты / Карта / …** —
  какие разделы интересны и откуда их выбирают;
- **Настроение → Тихая прогулка на природе** — какие настроения жмут;
- **Тег → тихо** — по каким тегам открывают ленту (ссылки с `?tag=`);
- **Поделиться → Место: Коломенское → Telegram** — чем делятся и куда;
- **Подборка → Вдоль реки → Главная** — какие подборки выбирают и откуда;
- **Случайное место → Открыто сейчас → Москвариум** — куда уводит «Удиви меня»;
- **Режим случайного места → Любое место** — пользуются ли вторым режимом;
- **Связаться → Царицыно → Звонок / Сайт** — кому звонят и на чей сайт уходят;
- **Канал → footer / collection** — откуда уходят в Telegram-канал;
- **Telegram → route** — какие рубрики канала приводят на сайт (метки
  рубрик — в `docs/telegram.md`). Те же переходы без цели видны в
  **Отчёты → Источники → Метки UTM**;
- `place`, `collection` — у какого места нажали маршрут, какую подборку
  открыли.

Запросы приводятся к нижнему регистру («Кафе» и «кафе» — одно) и
отправляются, когда человек перестал печатать (1,5 секунды), — иначе
«к», «ка», «каф» считались бы отдельными поисками.

Не считаются только те, кто отключил статистику в политике.

## Добавить новую цель

1. В коде: `import { goal } from '../core/analytics.js'` и в нужном
   месте `goal('my_goal')` (или `goal('my_goal', { что: 'угодно' })`).
2. В кабинете: цель «JavaScript-событие» с идентификатором `my_goal`.
