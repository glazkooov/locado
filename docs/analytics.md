# Яндекс Метрика

Счётчик **113169704**. Код — `scripts/core/analytics.js`.

## Как это устроено

1. Посетитель открывает сайт — Метрики на странице нет.
2. Нажимает «Хорошо» на плашке cookie — `consent.js` запоминает выбор
   и запускает `analytics.js`: тот подключает `tag.js` Яндекса и
   инициализирует счётчик. Дальше Метрика сама считает просмотры
   страниц, источники, устройства, время на сайте, клики по карте.
3. «Не надо» — `tag.js` не загружается вообще, цели не отправляются.
4. В важных местах сайт вызывает `goal('имя')` — это событие. В кабинете
   Метрики оно становится целью, только если там заведена цель с таким
   же идентификатором (см. ниже).

Вебвизор выключен (`webvisor: false`): он записывает действия
посетителя, и его пришлось бы отдельно описывать в политике.

## Цели — завести в кабинете

Метрика → счётчик → **Настройки → Цели → Добавить цель** →
тип **«JavaScript-событие»** → идентификатор из таблицы.

| Название цели | Идентификатор | Когда срабатывает |
|---|---|---|
| Построить маршрут | `route_click` | кнопка маршрута на странице места или подборки |
| Открыл подборку | `collection_open` | открыта страница подборки |
| Удиви меня | `random_open` | открыто «Случайное место» |
| Поиск | `search` | человек что-то искал в ленте |
| Поиск без результата | `search_empty` | по запросу ничего не нашлось |
| Предложить место | `suggest_open` | открыта форма «Предложить место» |
| Сообщить о неточности | `report_open` | открыта форма на странице места |
| Установка: открыл | `install_open` | нажал «Добавить на экран телефона» |
| Установка: установил | `app_install` | сайт установлен (только Android/Chrome) |

Цели считаются с момента, как их завели: задним числом события
в отчёт по целям не попадают.

## Где смотреть подробности

К целям прикреплены параметры — **Отчёты → Содержание → Параметры
визитов**:

- `search` / `search_empty` — что именно искали и не нашли;
- `place` — у какого места нажали маршрут или «неточность»;
- `collection` — какую подборку открыли.

Поисковый запрос отправляется, когда человек перестал печатать
(1,5 секунды), — иначе «к», «ка», «каф» считались бы отдельными поисками.

## Добавить новую цель

1. В коде: `import { goal } from '../core/analytics.js'` и в нужном
   месте `goal('my_goal')` (или `goal('my_goal', { что: 'угодно' })`).
2. В кабинете: цель «JavaScript-событие» с идентификатором `my_goal`.
